# .github

Shared GitHub settings for every repository on this account.

- `.github/ISSUE_TEMPLATE/quick_feature.yml` - **Quick feature**: one box, "What do you want?" (same label, picked up the same way).
- `.github/ISSUE_TEMPLATE/feature_request.yml` - the **Feature request** form shown on the Issues tab of every repository that doesn't have its own issue templates. Open an issue, choose "Feature request", fill it in.

Feature requests are reviewed at the start of each working session, built on a branch as a pull request, checked, and the issue is closed when the change is merged and live.
